# Lumix Tech Website

GitHub Pages-ready website for Lumix Tech and Qodex.

## Clean URLs

- Home: `/`
- Qodex: `/qodex/`
- Privacy Policy: `/privacy/`
- Help & Support: `/support/`

The project uses folder-based `index.html` files so `.html` does not appear in the public URLs.

## Assets

All website images are included in `assets/`. Keep the complete `assets` folder when uploading to GitHub.

## GitHub Pages

1. Upload the complete project contents to the repository root.
2. Keep `CNAME` in the root with `lumixtech.in`.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, folder `/ (root)`, and save.
5. Wait for the deployment to complete.

If an older version of the repository contains `qodex.html`, `qodex-support.html`, or `qodex-privacy.html`, remove those old files after uploading this version so the repository contains only the clean folder-based pages.
